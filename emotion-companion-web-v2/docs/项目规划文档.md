# 情感陪护数字人系统 - 项目规划文档

## 一、项目概述

### 1.1 项目背景
随着社会压力增大，越来越多人面临情绪困扰和心理问题。传统心理咨询存在以下痛点：
- **时间限制**：咨询师工作时间固定，无法 24 小时提供服务
- **成本高昂**：专业心理咨询费用较高，普通人难以长期负担
- **隐私顾虑**：面对面咨询让部分人感到不适
- **资源稀缺**：优质心理咨询师数量有限，预约困难

### 1.2 项目目标
开发一款基于 AI 的情感陪护数字人系统，提供：
- 24 小时在线情感陪伴
- 低成本心理健康支持
- 私密安全的倾诉环境
- 智能化的情绪识别与疏导

## 三、功能详细描述

### 3.1 AI 情感对话系统

**技术实现**：
- 使用 **SiliconFlow DeepSeek-V3** 大模型（671B 参数）
- 专业心理咨询师人设 prompt 设计
- 支持认知行为疗法（CBT）和正念减压技巧

**核心能力**：
1. **情绪识别**：自动识别用户情绪状态（开心、难过、焦虑、愤怒等）
2. **共情回应**：用温暖、专业的语言回应，让用户感到被理解
3. **实用建议**：提供具体可行的情绪调节技巧
4. **安全边界**：遇到严重情况建议寻求专业帮助

**回复示例**：
```
用户："最近工作压力好大，晚上睡不着"
AI："听起来你最近承受了很大的压力 💤 失眠是身体在提醒你需要放松了。
    试试今晚睡前做5分钟深呼吸，把注意力放在呼吸上。
    需要我教你具体的放松技巧吗？"
```

### 3.2 语音播报系统

**技术实现**：
- **SiliconFlow TTS** (CosyVoice2-0.5B 模型)
- 音色：diana（欢快女声）
- 支持语速调节

**使用场景**：
- 用户点击语音按钮播放 AI 回复
- 支持自动播放最新消息
- 可随时暂停/继续

### 3.3 3D 数字人实时互动

**技术实现**：
- **百度智能云数字人**
- 形象：馨月-半身交互
- 声音：度嫣然（CAP_4194）

**功能特点**：
- 实时视频通话式交互
- 口型与语音同步
- 支持语音输入（语音识别）
- 单次会话最大 5 分钟

**使用方式**：
- 用户点击"连接数字人"按钮
- 建立 WebRTC 实时连接
- 可与数字人进行面对面交流

### 3.4 用户管理系统

**功能模块**：
1. **注册/登录**：JWT 认证，安全可靠
2. **个人中心**：查看个人信息、设置偏好
3. **聊天历史**：保存所有会话记录
4. **情绪统计**：可视化展示情绪变化趋势

## 五、技术栈

### 5.1 前端
- **框架**：Next.js 16 + React 19
- **语言**：TypeScript
- **样式**：Tailwind CSS
- **状态管理**：Zustand
- **UI 组件**：shadcn/ui
- **动画**：Framer Motion

### 5.2 后端
- **框架**：Express.js
- **语言**：TypeScript
- **数据库**：MySQL + Prisma ORM
- **认证**：JWT

### 5.3 AI 服务
- **对话模型**：SiliconFlow DeepSeek-V3
- **语音合成**：SiliconFlow CosyVoice2-0.5B
- **数字人**：百度智能云
