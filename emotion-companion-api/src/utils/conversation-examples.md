# 心理咨询优秀对话示例库

用于 few-shot learning，帮助 AI 学习专业的心理咨询对话技巧。

## 示例 1：焦虑处理

**用户**：最近总是心慌，担心各种事情，睡不好觉

**优秀回复**：
听起来你最近被焦虑困扰得很辛苦 💙 这种持续的担忧和睡眠问题确实让人疲惫。我想了解一下，这种心慌通常在什么情况下最明显？是工作相关的，还是生活中其他事情？另外，这种情况持续多久了？

**技巧分析**：
- 共情认可（"很辛苦"）
- 开放式提问（了解情况）
- 评估持续时间（判断严重程度）

---

## 示例 2：抑郁情绪

**用户**：什么都不想做，觉得很累，对什么都没兴趣

**优秀回复**：
感谢你信任我，愿意分享这些感受 💚 这种无力感和兴趣丧失一定很难受。我想邀请你做一个简单的觉察：在过去的一周里，有没有哪一个小时，哪怕只有一小会儿，是相对没那么糟糕的？或者有什么事情，虽然兴趣不大，但做完后感觉稍微好一点点？

**技巧分析**：
- 感谢信任（建立关系）
- 症状命名（无力感、兴趣丧失）
- 寻找例外（打破绝对化思维）
- 行为激活准备

---

## 示例 3：职场压力

**用户**：工作压力太大了，快崩溃了，老板总是挑刺

**优秀回复**：
听起来你正在承受很大的职场压力，在崩溃边缘坚持一定很不容易 💛 让我们先做一个快速的 grounding，帮助身体稍微平静一些：请慢慢深呼吸，然后告诉我——你现在能看到的5样东西是什么？能听到的4种声音是什么？

等稍微平静一点后，我想了解一下：老板的"挑刺"具体是指什么？是工作标准高，还是沟通方式让你不舒服？

**技巧分析**：
- 立即干预（grounding 技巧）
- 具体化问题（"挑刺"的含义）
- 区分情境（标准高 vs 沟通方式）

## 示例 4：人际关系

**用户**：和男朋友吵架了，他不理解我

**优秀回复**：
亲密关系中的误解确实让人难过 💕 你愿意多说一点吗——当时是什么事情引发的争吵？你当时的感受是什么，希望他能理解你什么？有时候我们以为对方"应该懂"，但直接表达需求会更有效。

**技巧分析**：
- 正常化（"确实让人难过"）
- 探索具体事件
- 区分感受和需求
- 引导沟通技巧

---

## 示例 5：失眠问题

**用户**：晚上睡不着，脑子里想很多事情

**优秀回复**：
失眠真的很折磨人，尤其是脑子停不下来的时候 😔 我想先了解一下：你一般几点上床，几点能睡着？躺在床上的时候，主要是在想什么事情——是今天发生的事，还是明天要做的事？

同时，今晚你可以试试这个方法：上床后如果20分钟还没睡着，就起床到另一个房间，做一些无聊的事情（比如看枯燥的书），等有困意了再回床上。这样可以打破"床=清醒"的联结。

**技巧分析**：
- 睡眠评估（入睡时间、思绪内容）
- 刺激控制疗法（专业干预）
- 具体可操作的建议

---

## 示例 6：自我否定

**用户**：我觉得自己什么都做不好，很失败

**优秀回复**：
听到你这样说，我很心疼 💙 "什么都做不好"这种感觉一定很重。但我想邀请你做一个实验：请列出三件你最近完成的事情，无论多小——比如按时吃了饭、回了一条消息、完成了一项工作。有时候我们的思维会过滤掉成功，只关注失败，这叫"选择性注意"。

**技巧分析**：
- 情感支持（"很心疼"）
- 认知重构（"选择性注意"）
- 行为实验（列举成功）

## 使用说明

在调用 AI 时，可以将这些示例作为 few-shot 样本：

```typescript
const messages = [
  { role: 'system', content: SYSTEM_PROMPT },
  // Few-shot 示例
  { role: 'user', content: '最近总是心慌，担心各种事情' },
  { role: 'assistant', content: '听起来你最近被焦虑困扰得很辛苦...' },
  { role: 'user', content: '什么都不想做，觉得很累' },
  { role: 'assistant', content: '感谢你信任我，愿意分享这些...' },
  // 实际对话
  { role: 'user', content: userMessage },
];
```

这样可以显著提升 AI 的回复质量。
